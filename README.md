# Homework Book Firebase setup

Publish `FIREBASE_RULES.json` in Firebase Realtime Database > Rules. Add your Vercel domain in Firebase Authentication > Settings > Authorized domains. Deploy this folder through HTTPS, then use the same Google or email/password account on each device.

Phone/SMS sign-in is excluded because it requires Firebase's pay-as-you-go plan. This version uses only Google and email/password sign-in with Realtime Database.
